# 匿名投稿Bot

Slackのスラッシュコマンドを利用して、チャンネルやスレッドに匿名でメッセージを投稿できるBotです。AWS LambdaとSlack APIを利用して実装しています。

## 背景・目的

学生コミュニティの運営でSlackを利用する中で、匿名で意見や情報を投稿できる仕組みを実現するために開発しました。

既存の技術記事などを参考にしながら、Slackからのリクエストの受信、投稿内容の解析、Slack APIを通じたメッセージ送信までの一連の処理を実装しました。

## 主な機能

- **匿名投稿**：`/ano` コマンドでチャンネルにメッセージを投稿
- **匿名スレッド返信**：`/re-ano` コマンドとSlackの投稿URLから返信先を特定し、スレッドにメッセージを投稿
- **投稿先の指定**：投稿URLからチャンネルIDとタイムスタンプを抽出し、返信先を特定
- **アクセス制御の仕組み**：ユーザーIDやチャンネルIDに基づいて利用可否を判定する処理を用意

## 使用技術

- Python
- AWS Lambda
- Amazon API Gateway
- Slack API（`chat.postMessage`）
- Python標準ライブラリ（`urllib`、`urllib.parse`、`base64`、`json`、`re`）

## システム構成

Slackのスラッシュコマンドから送信されたリクエストをAPI Gateway経由でLambdaが受け取り、内容を解析したうえでSlack APIを呼び出します。

```text
Slack Slash Command
        ↓
Amazon API Gateway
        ↓
AWS Lambda (Python)
        ↓
Slack API (chat.postMessage)
        ↓
指定チャンネル / スレッド
```

## 使い方

### 1. チャンネルへの匿名投稿

```text
/ano こんにちは
```

指定されたチャンネルにメッセージを投稿します。

### 2. スレッドへの匿名返信

```text
/re-ano https://workspace.slack.com/archives/CHANNEL_ID/pTIMESTAMP こんにちは
```

Slackの投稿URLからチャンネルIDとタイムスタンプを抽出し、該当するスレッドにメッセージを投稿します。

※ `CHANNEL_ID` と `TIMESTAMP` は説明用のプレースホルダーです。実際には対象の投稿URLを使用します。

## 実装上の工夫

- **リクエストの解析**：Base64エンコードされたリクエストボディをデコードし、フォーム形式のパラメータを解析
- **投稿先の特定**：正規表現を利用してSlackの投稿URLからチャンネルIDとタイムスタンプを抽出
- **処理の共通化**：チャンネルへの投稿とスレッドへの返信で、メッセージ送信処理を共通化
- **エラーハンドリング**：例外発生時にエラーをログへ出力し、投稿失敗を呼び出し元へ返す
